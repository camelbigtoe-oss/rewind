# Rival portraits

Drop painted portraits here as `<id>.webp` (or .png, then update the path in cast.js), then add the id to
`ART` in cast.js. Ids: remix, tiff, gus, spinz, moxie, pete, sheila, couch, exec.
Portrait framing: head and shoulders, about 1000x1200, character facing slightly left, transparent or plain background.
